
SCRAMI AI — Android v1

Что это:
Личное Android-приложение с чатом Scrami AI, подключённым к OpenAI Responses API.
История чата хранится локально на устройстве.

Как собрать APK:
1. Открой папку ScramiAI в Android Studio.
2. Дождись синхронизации Gradle.
3. Build → Build APK(s).
4. APK появится в app/build/outputs/apk/debug/.

Первый запуск:
1. Открой ⚙.
2. Вставь свой OpenAI API key.
3. Оставь модель gpt-6-luna или укажи доступную тебе модель.
4. Сохрани.
5. Напиши сообщение.

Важно:
- API-ключ не отправляй в чат.
- Ключ хранится на устройстве через Android Keystore.
- Для публичного приложения лучше не хранить API-ключ на клиенте вообще: нужен собственный сервер-прокси.
- Для следующей версии можно добавить полноценную долгосрочную память, голос, изображения, файлы, веб-поиск и Telegram.
